# 打卡日程表 · Habit Tracker

🗓 **在线使用 → https://daka.startian.top/**

> 一个轻量的习惯打卡小应用：自定义目标、每天一键打卡、连续天数与月度日历回顾。零依赖单文件、打开即用、数据只存浏览器本地。

## 功能

- **目标模板一键添加**：早睡 / 喝水 / 运动 / 阅读 / 刷牙 / 睡前不玩手机……也可以自己创建
- **自定义目标**：图标 + 主题色 + 每周目标次数
- **日常打卡**：每天一键打卡，实时看连续天数、累计打卡、本月完成
- **月度日历**：一眼回顾这个月哪天打了卡、哪天断了
- **成就系统**：10 枚成就（启程 / 七日之火 / 今日全勤 / 自律伊始……），与小站跨站成就柜互通
- **数据自由**：导出 / 导入 JSON 备份，离线完全可用

## 技术说明

- 单文件、零依赖、纯前端（无框架、无构建步骤）
- 数据存浏览器 localStorage，不上传、不登录
- 卡片 / 连续天数 / 日历的交互参考了「小日常」的模式，实现为自研代码
- 属于「星恬的小站」作品之一
